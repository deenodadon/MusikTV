# Download Musik TV

**[Download version 0.2.3](https://github.com/deenodadon/MusikTV/raw/refs/heads/main/downloads/MusikTV-0.2.3.apk)**

**[Download the latest APK](https://github.com/deenodadon/MusikTV/raw/refs/heads/main/downloads/MusikTV-latest.apk)**

Sign in to GitHub first if this repository is private. Save the file as an `.apk`
and open it on Android TV with installation allowed for your downloader/file manager.
Do not unzip the file. The SHA-256 checksum is provided beside the APK.

The latest file is the tested build from this environment. APKs use the same
signing identity so 0.2.3 can update earlier builds without uninstalling.
The latest APK is an optimized, non-debuggable release build. It retains the
earlier debug signing certificate for updates and is not a Play Store package.
Settings shows the actual version and Optimized build status.
See the project README and validation report for features and compatibility limits.
